# Офис — контекст проекта для Claude Code

## Владелец и правила общения

- Владелец — не программист. Живёт в Астане, занимается маркетингом и SMM в строительной компании, которая продаёт квартиры в ЖК (строится «2 очередь»). Общаться **только по-русски**, простыми словами, без жаргона. Команды давать пошагово: что нажать и куда вставить.
- **Порядок работы над новой функцией:** сначала задать уточняющие вопросы, потом предложить варианты улучшений, и только после ответа браться за код.
- **Главное требование — экономия ресурсов и токенов.** Проект только для себя, продавать его не будут.
- Публикации, сообщения людям и любые траты (кредиты, платные API) — только после явного подтверждения владельца. Сотрудники офиса готовят только черновики, публикует владелец сам. **Исключение (решение владельца 12.10.2026):** «Пакет недели» Мадины офис публикует в Instagram сам по расписанию — только после кнопки владельца «Утвердить пакет» (`server/smm-pack.js`).
- WhatsApp: **никакого WhatsApp Web и неофициальных API**. Нужны нулевой риск блокировки и бесплатность. Вместо этого — Google Форма «Итог диалога» и официальный экспорт чатов.
- В Казахстане отзывы и карты — это 2ГИС, а не Google Карты.

## Что это

Локальный «виртуальный офис»: ИИ-сотрудники — это короткие запуски `claude -p` по подписке владельца (Claude Max 5x). Есть пиксельный экран в браузере (http://localhost:3777) и Telegram-бот. Владелец даёт поручение руководителю → руководитель возвращает план (JSON-схема) → владелец утверждает → диспетчер раздаёт задачи. Общение идёт только через руководителя; прямые задачи сотруднику тоже возможны.

С 08.10.2026 офис работает **на сервере** круглосуточно (см. «Сервер»), портал — https://office.example.com. Компьютер владельца — Windows: там разработка (этот репозиторий), оттуда код выкладывается на сервер. `start.bat` больше не запускать.

## Как запускаются сотрудники (не ломать экономию)

```
claude -p --output-format stream-json --verbose --model M --effort E --system-prompt <роль>
  --tools <список или ""> --strict-mcp-config --restricted --no-session-persistence
  --max-turns N --max-budget-usd X [--permission-mode acceptEdits] [--json-schema ...]
```

- Промпт задачи передаётся через stdin. `ANTHROPIC_API_KEY` и `ANTHROPIC_AUTH_TOKEN` удаляются из окружения, чтобы работа шла по подписке, а не по API.
- Замеры (v2.1.285):
  - пустой запуск — около 860 входящих токенов (без флагов — 20–60 тыс.);
  - план руководителя — примерно $0.005;
  - задача SMM на haiku — $0.026.
- С `--restricted` сотрудники **не видят** этот CLAUDE.md и `~/.claude/CLAUDE.md` (проверено). Флаг `--bare` не использовать: он отключает вход по подписке.
- Haiku выдумывает факты, поэтому SMM по умолчанию работает на sonnet.
- Лимит подписки берётся из события `rate_limit_event` (`unifiedWindows.five_hour` / `seven_day`: `utilization` от 0 до 1, `resetsAt` в секундах).

## Разработка

- Node ≥ 20, **без зависимостей** (только встроенные модули), ESM, без точек с запятой, 2 пробела. Тексты интерфейса — по-русски, комментарии в коде — по-английски и редко.
- Запуск: `node server/main.js --no-browser`.
  - Для дешёвых тестов пропишите в `data/config.json`: `"employees": {"manager": {"model": "haiku"}, "smm": {"model": "haiku", "effort": "low"}}`. Потом верните как было.
  - Останавливать по pid, а не через `pkill -f "server/main.js"`: такой шаблон совпадает с командной строкой самой оболочки.
- Интерфейс проверять в браузере (Playwright), смотреть консоль на ошибки.
- `data/`, `work/`, `inbox/*`, `knowledge/*` в git не попадают — это данные владельца.
- `start.bat` должен оставаться в CRLF (см. `.gitattributes`).
- Ветка: `claude/project-overview-kibk75`. Прошлый проект (PIKIR) удалён; восстановить: `git checkout 2fe614b -- .`
