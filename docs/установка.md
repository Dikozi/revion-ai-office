# Офис — ваша команда ИИ-сотрудников

Пиксельный офис, где работают ИИ-сотрудники на базе Claude Code. Вы даёте поручение руководителю, он составляет план, вы его утверждаете, и сотрудники берутся за работу. На экране видно, кто чем занят. Если нажать на сотрудника, откроется его журнал действий, очередь задач и готовые результаты. Управлять офисом можно и с телефона, через Telegram.

Офис работает на вашем компьютере, пока тот включён. Тратится только лимит вашей подписки Claude, отдельной оплаты нет. Сотрудник запускается под конкретную задачу и после неё закрывается, поэтому в простое офис ничего не расходует.

## Что уже умеет (этап 1)

| | |
|---|---|
| **Руководитель** | принимает поручения, составляет план и ждёт вашего «Утвердить». Если поручение непонятно — задаёт вопрос |
| **SMM** | посты, сторис, контент-план, УТП и готовые картинки в стиле Altyn Qala (офис сам рисует их через Chrome). Факты берёт только из базы знаний |
| **Монтажёр** | Reels на 15 секунд из ваших видео со стройки: выбирает 3 лучших момента, сверху «Ход строительства», «2 очередь» и дата. Без звука — музыку ставите при публикации |
| **Маркетолог-аналитик** | разбор недели по Instagram и рекламе Meta: что сработало, лучшие креативы, советы и задания для SMM. Нужен токен Meta (⚙ → Meta), доступ только на чтение |
| **Аналитик продаж** | этап 3 (шахматка, итоги диалогов, частые вопросы и возражения) |

Ещё в этапе 1:
- экран офиса с анимацией, журналом действий и результатами;
- счётчик лимита подписки (5 часов и неделя);
- Telegram-бот: поручения, фото, утверждение планов кнопками, готовые файлы прямо в чат.

**Сотрудники ничего не публикуют и никому не пишут.** Они готовят черновики, а публикуете вы сами.

## Установка на Windows

Понадобится около 20 минут. Каждый шаг делается один раз.

### 1. Node.js

Скачайте версию **LTS** с [nodejs.org](https://nodejs.org) и установите, нажимая «Далее» во всех окнах.

### 2. Git for Windows

Он нужен для работы Claude Code. Скачайте с [git-scm.com/download/win](https://git-scm.com/download/win) и установите с настройками по умолчанию.

### 3. Claude Code

1. Нажмите **Пуск**, введите `PowerShell` и откройте его.
2. Вставьте команду и нажмите Enter:
   ```
   irm https://claude.ai/install.ps1 | iex
   ```
3. Когда установка закончится, **закройте PowerShell и откройте его заново**.
4. Введите `claude` и нажмите Enter. Выберите вход через аккаунт Claude (подписка Max) и войдите в открывшемся браузере.
5. Если Claude ответил и ждёт ввода, всё работает. Закройте окно.

> Вход нужен один раз. Офис пользуется этим же входом.

### 4. Сам офис

Откройте PowerShell и вставьте команду:
```
git clone https://github.com/Dikozi/revion-ai-office.git C:\office
```
Проект появится в папке `C:\office`. Дважды щёлкните в ней **`start.bat`**.

> Можно и без git: на GitHub нажмите **Code → Download ZIP** и распакуйте архив в `C:\office`. Но тогда Claude на вашем компьютере не сможет сам сохранять и получать обновления.

Откроется чёрное окно (это и есть работающий офис), а через секунду — браузер со страницей офиса. Если браузер не открылся, откройте вручную: **http://localhost:3777**

Пока офис нужен, **не закрывайте чёрное окно**. Чтобы выключить офис, закройте это окно.

### 5. Проверка

Напишите в строке сверху: `Придумай 3 идеи для сторис про наш ЖК`. Через 10–30 секунд над офисом появится план. Нажмите **Утвердить**, и SMM возьмётся за работу. Результат откроется по клику и придёт уведомлением.

### 6. Telegram (по желанию, но удобно)

1. В Telegram откройте **@BotFather** и отправьте `/newbot`. Придумайте имя и адрес бота (адрес должен заканчиваться на `bot`).
2. BotFather пришлёт токен — длинную строку с двоеточием.
3. В офисе нажмите **⚙** справа сверху, вставьте токен и нажмите «Сохранить».
4. Нажмите «Открыть бота» или отправьте боту `/start` с шестизначным кодом, который показан на экране.

С этого момента бот отвечает только вам. Что можно делать в боте:
- отправить текст — это поручение руководителю, план придёт с кнопками «Утвердить» и «Отклонить»;
- отправить фото с подписью — поручение с материалами;
- отправить фото без подписи — бот сохранит его и приложит к следующему поручению;
- `/smm текст` — задача напрямую SMM, без плана;
- `/status` — кто чем занят;
- `/clear` — забыть сохранённые фото.

Бот работает, пока включён офис на компьютере.

### Автозапуск вместе с Windows (по желанию)

Нажмите `Win + R`, введите `shell:startup` и нажмите Enter. В открывшуюся папку перетащите **ярлык** на `start.bat` (перетаскивайте правой кнопкой мыши и выберите «Создать ярлык»).

## Первое, что стоит заполнить: база знаний

Папка **`knowledge`** — это память офиса. Всё, что в ней лежит, сотрудники читают перед каждой задачей и берут факты только оттуда. Чем полнее база, тем точнее тексты.

Что положить в неё (подробнее в `knowledge/README.md`):
- характеристики ЖК: очереди, сроки, площади, отделка, двор, паркинг;
- цены и акции;
- тон бренда, примеры хороших постов и запрещённые обещания;
- контакты отдела продаж;
- логотип.

Это обычные текстовые файлы. Их можно создать в Блокноте и сохранить с расширением `.md` или `.txt`.

## Как пользоваться

- **Поручение руководителю** пишется в строке сверху. Можно приложить файлы кнопкой 📎, перетащить их в окно или вставить картинку через Ctrl+V.
- **План** появляется над офисом. Вы нажимаете «Утвердить» или «Отклонить». Если руководитель задал вопрос, ответьте прямо в карточке.
- **Прямая задача сотруднику:** нажмите на него и заполните «Поставить задачу напрямую». Так быстрее и дешевле, но только для одного сотрудника.
- **Результат** откройте в списке «Готовые результаты». Текст можно скопировать одной кнопкой, файл — скачать.
- **Все файлы задач** лежат в папке `work` (у каждой задачи своя подпапка). Вложения, которые вы присылали, — в папке `inbox`.

## Как офис экономит лимит

- Сотрудник запускается под одну задачу и закрывается после неё. В простое расход — ноль.
- Каждый сотрудник запускается в облегчённом режиме: без лишних инструментов, плагинов и истории. Вход примерно в 1 тыс. токенов вместо 20–60 тыс. при обычном запуске.
- Руководитель только планирует, это очень короткий запуск.
- У каждого сотрудника есть потолок ходов и бюджета на задачу, и одна задача не может съесть весь лимит.
- Одновременно работают не больше двух сотрудников.
- Сумма в долларах в карточке задачи — это оценка по ценам API. По подписке деньги не списываются, тратится только лимит (он показан сверху справа).

## Тонкая настройка

После первого запуска появится файл `data\config.json`. Его можно открыть Блокнотом:

| Поле | Что значит |
|---|---|
| `port` | адрес офиса, по умолчанию `3777` → http://localhost:3777 |
| `maxParallel` | сколько сотрудников работают одновременно (по умолчанию 2) |
| `taskTimeoutMin` | через сколько минут задача останавливается принудительно |
| `openBrowser` | открывать ли браузер при запуске |
| `claudePath` | путь к `claude.exe`, если офис не нашёл его сам |
| `browserPath` | путь к Chrome или Edge для картинок, если офис не нашёл его сам |
| `ffmpegPath` | путь к `ffmpeg.exe` для монтажа, если офис не нашёл его сам |
| `employees` | переопределить модель сотрудника, например `"smm": { "model": "haiku" }` — дешевле, но чаще ошибается в фактах |

После правки перезапустите офис.

## Если что-то не так

| Проблема | Что сделать |
|---|---|
| «Не найден Node.js» | установите Node.js LTS (шаг 1) и запустите `start.bat` снова |
| «Claude Code не найден» | выполните шаг 3. Если Claude установлен нестандартно, пропишите путь в `claudePath` |
| Задачи падают с ошибкой авторизации | откройте PowerShell, введите `claude` и войдите заново |
| «Порт 3777 занят» | офис уже запущен — откройте http://localhost:3777. Или поменяйте `port` в настройках |
| Бот не отвечает | офис должен быть запущен. Проверьте в ⚙, что бот привязан |
| Лимит подписки кончился | задачи будут падать до сброса. Время сброса видно, если навести мышь на шкалу сверху |

Ваши данные (задачи, настройки, результаты) лежат в папках `data`, `work`, `inbox` и `knowledge`. При обновлении офиса эти четыре папки сохраните, а остальное замените новой версией.

## Дорабатывать офис вместе с Claude на своём компьютере

1. Установите всё по шагам 1–4 выше (проект скачивайте через `git clone`).
2. Откройте Claude Code: в приложении Claude на компьютере вкладка **Code** → выберите папку `C:\office`. Или в PowerShell: `cd C:\office`, затем `claude`.
3. Claude сам прочитает `CLAUDE.md`: там всё о проекте, ваши правила и план этапов. Объяснять заново ничего не нужно.
4. Первое поручение: «Запусти офис и проверь, что всё работает на Windows».

Перед изменениями закройте работающий офис или попросите Claude его перезапустить.
