# REVION для общепита: план портала и сценарий ролика

*Составлено 20.11.2026 по обсуждению с владельцем. Демо-экраны для показа — 3 слайда «REVION · ресторан» (выдуманные цифры). Пока это план: в коде офиса ничего для общепита нет, и данные застройщика с общепитом не смешиваются — для каждого заведения своя копия офиса (свой бот, портал, данные).*

## 1. Зачем это ресторану

**Выручка = гости × средний чек × как часто возвращаются.** Портал каждый день показывает, какой из трёх множителей просел и почему, и ловит деньги, которые утекают: фудкост, удаления на кассе, скидки, пустые часы.

Что получает собственник:

- одну строку в Telegram в 9:00 вместо сбора цифр из кассы, таблиц, Instagram и 2ГИС;
- до 3 дел «Сделать сегодня» с кнопками «Утвердить / Не надо»;
- сторожей, которые замечают проблему в тот же день (без ИИ, бесплатно);
- отчёт недели на 1 странице и отчёт месяца с историей всех месяцев;
- ИИ-сотрудников, которые готовят контент, рекламу, ответы на отзывы и советы — публикуется только после утверждения.

## 2. Откуда берём данные

| Источник | Что даёт | Что нужно от заведения |
|---|---|---|
| **Касса iiko** (сервер iiko, OLAP-отчёты) — главный | выручка по чекам, часам и дням, блюда, официанты, оплаты, скидки, удаления, себестоимость | адрес сервера iiko и отдельный пользователь **только на чтение**; уточнить у дилера iiko, нужна ли лицензия на API |
| **iikoCloud** (если есть доставка или карта лояльности) | заказы доставки, гости по карте → возвращаемость | ключ API из iikoWeb (Cloud API → «Добавить интеграцию») |
| **Таблица собственника** (Google Таблица) | аренда, зарплаты, закупки, коммуналка, план месяца → **прибыль** | ссылка «только чтение»; выручку из таблицы не берём — в iiko она точнее |
| **Instagram и реклама Meta** | подписчики, охват, посты, Reels, сторис, реклама → переписки → брони | доступ к бизнес-кабинету (как у застройщика) |
| **2ГИС** | рейтинг, отзывы, клики на телефон и WhatsApp | доступ к кабинету 2ГИС или раз в неделю цифры в бот |
| **Агрегаторы** (Wolt, Glovo, Яндекс Еда) | заказы и комиссия по каждому | выгрузка отчёта из их кабинетов |
| **Брони столов** | откуда пришёл гость | ссылки WhatsApp с меткой источника (как у застройщика: «Пишу из Instagram», «…из 2ГИС», код объявления) и книга броней, если есть |

## 3. Топ-10 показателей

| # | Показатель | Как считаем | Норма / сторож |
|---|---|---|---|
| 1 | **Выручка по дням и часам** | касса; сравнение с тем же днём прошлой недели и средним за 4 таких дня | ниже нормы дня на 15%+ — сигнал; провал по часам — красным |
| 2 | **Чеки и средний чек** | число чеков, выручка ÷ чеки | понятно, что просело: гости или чек |
| 3 | **Средний чек по официантам** и позиций в чеке | касса по официанту | «если все допродают как лучший — +N ₸ в месяц» |
| 4 | **Меню: ABC-анализ** | выручка и маржа каждого блюда | «звёзды», «поднять цену», «убрать» |
| 5 | **Фудкост** | себестоимость ÷ выручка (по техкартам iiko) | норма ≈ 25–35%; рост 2 недели подряд — сигнал с причиной (что подорожало) |
| 6 | **Удаления, отмены, скидки** | после пречека, по официанту и смене | выше обычного — сигнал в тот же день |
| 7 | **Загрузка по часам** | чеки и выручка по часам | сколько персонала ставить; «пустые» часы → акции |
| 8 | **Возвращаемость гостей** | карта лояльности или телефон (обезличенно) | доля вернувшихся за 30 дней |
| 9 | **Рейтинг и отзывы 2ГИС** | рейтинг по месяцам, отзывы своими словами | отзыв 1–3★ — тревога и черновик ответа |
| 10 | **Доставка** | доля, агрегаторы, комиссия | где маржа выше, куда направлять гостей |

Плюс **прибыль месяца**: выручка − себестоимость − расходы из таблицы.

## 4. Разделы портала

1. **Главная «Утро собственника»** — 5 цифр (выручка вчера к прошлому такому же дню, чеки, средний чек, фудкост недели, выручка месяца с прогнозом плана), «Сделать сегодня» (до 3 дел), выручка по часам, строка «Данные: касса ✓ · таблица ✓ · Instagram ✓ · 2ГИС ✓».
2. **Продажи** — по дням, неделям и месяцам; чеки и средний чек; загрузка по часам; доставка.
3. **Меню** — ABC-анализ, маржа блюд, фудкост по неделям и по блюдам, подорожания закупок.
4. **Зал и персонал** — официанты: средний чек, позиций в чеке, допродажи, удаления; совет по сменам.
5. **Потери** — удаления после пречека, отмены, скидки, списания: сумма, кто, когда.
6. **Гости** — возвращаемость, частота визитов, **портрет клиента** (раздел 6).
7. **Маркетинг** — Instagram, реклама Meta → переписки → брони → пришли гости → выручка, цена брони, источники гостей, 2ГИС.
8. **Отчёты** — неделя (1 страница), месяц (PDF + Excel), история всех месяцев, графики роста.
9. **План и решения** — цели месяца, советы с кнопкой «Утвердить», замер результата через 7 дней, память решений.

Каждый день в 9:00 — строка в Telegram: «Вчера 1,21 млн ₸ (−8% к прошлому чт), 214 чеков, средний чек 5 673 ₸. Провал 15–18 ч. 6 удалений у одного официанта. 2ГИС: новый отзыв 2★ — ответ готов».

## 5. Instagram-аналитика

- **Подписчики** — живой счётчик каждый час; скачок «3× нормы» → разбор причины (реклама, Reels, отметка блогера).
- **Охват, посещения профиля, клики на WhatsApp и звонок** — по дням и месяцам, история хранится навсегда (Meta старые данные стирает).
- **Каждый пост и Reels** — замер через 3 и 7 дней: охват, сохранения, репосты, досмотры; сторис — пока живы, каждый час.
- **Что работает** — сравнение по темам: блюдо крупно / кухня и повар / атмосфера и люди / акции; время публикации; лучшие форматы становятся образцами для Мадины.
- **Instagram → брони** — сколько гостей пришло по метке «Пишу из Instagram» и сколько они принесли.
- **Контент на неделю** — пакет Мадины (посты, сторис, видео с музыкой) публикуется сам по расписанию после одной кнопки «Утвердить».

## 6. Портрет клиента

Три ступени — от «кто смотрит» до «кто платит»:

| Ступень | Откуда | Что видно |
|---|---|---|
| **Кто подписан и реагирует** | Instagram (бесплатно) | возраст, пол, город подписчиков и тех, кто реагирует |
| **Кто пишет и бронирует по рекламе** | реклама Meta | возраст и пол, цена брони по каждой группе, доля пришедших |
| **Кто приходит и платит** | касса и карта лояльности | когда приходит, сколько гостей за столом, средний чек, что заказывает, как часто возвращается |

Из кассы складываются **сегменты гостей** (пример):

| Сегмент | Когда | Ср. чек | Что предлагать |
|---|---|---|---|
| Бизнес-ланч | будни 12–15 | ниже среднего | быстрая подача, кофе и десерт к обеду |
| Семейный ужин | пт–вс 18–21 | выше среднего, 3–5 гостей | детское меню, бронь стола заранее |
| Компании и праздники | вечер, банкеты | самый высокий | пакеты банкетов, предзаказ |
| Доставка | вечер, будни | средний | своя доставка выгоднее агрегаторов |

По каждому сегменту — доля выручки, рост или падение, откуда приходят (Instagram, 2ГИС, реклама, повторные) и совет, на кого направить рекламу. Личные данные гостей (имена, телефоны) ИИ не видит — только обезличенные итоги.

## 7. Сторожа (без ИИ, бесплатно)

- выручка ниже нормы этого дня недели; провал по часам;
- удаления, отмены, скидки выше обычного — по официанту и смене;
- фудкост растёт 2 недели подряд; блюдо выпало из продаж;
- отзыв 1–3★ в 2ГИС; рейтинг снижается;
- реклама дорожает или тратит без броней; кабинет Meta остановлен;
- источник данных молчит больше 3 часов.

## 9. Этапы внедрения

| Неделя | Что делаем | Что получает собственник |
|---|---|---|
| 1 | доступы (iiko на чтение, Meta, таблица, 2ГИС), своя копия офиса, бот | бот и портал с входом |
| 2 | касса: главная, продажи, утренняя строка, сторожа кассы | цифры каждое утро, первые сигналы |
| 3 | меню, фудкост (нужны техкарты в iiko), персонал, потери | ABC-меню, официанты, удаления |
| 4 | маркетинг, Instagram, 2ГИС, отчёты недели и месяца | первый отчёт недели, источники гостей |
| 5+ | доставка, лояльность, портрет клиента по кассе, прогноз месяца | сегменты гостей, прогноз |

**Чек-лист от заведения:** адрес сервера iiko и пользователь «только чтение»; техкарты (себестоимость) в iiko; ссылка на таблицу расходов; доступ к бизнес-кабинету Meta; кабинет 2ГИС; кабинеты агрегаторов; есть ли карта лояльности.

**Цель на 3 месяца** ставим вместе с собственником после первых 2 недель цифр (например: средний чек +5–10%, потери на удалениях и скидках ниже нормы, рейтинг 2ГИС +0,2).

## 10. Сценарий моушн-ролика (≈ 90 секунд, 9:16 и 16:9)

Стиль: экраны портала в палитре REVION, цифры «бегут», графики вырастают, мягкий современный бит. Голос — спокойный мужской или женский, по-русски. Все цифры — демо.

| Время | На экране | Голос за кадром |
|---|---|---|
| 0–5 с | Тёмный экран, крупно: «1,21 млн ₸» → зачёркивается → «1,4 млн ₸» | «Вчера ваш ресторан заработал 1,2 миллиона. А мог — 1,4.» |
| 5–13 с | Собственник утром: касса, таблица, Instagram, отзывы — окна разлетаются хаотично | «Касса — в одном месте, расходы — в таблице, отзывы — в 2ГИС. Пока соберёшь — день прошёл.» |
| 13–19 с | Окна собираются в логотип REVION (знак R из лент) | «REVION собирает всё в одну картину. Каждое утро.» |
| 19–30 с | Телефон: в 9:00 приходит строка в Telegram; затем главная «Утро собственника», 5 цифр отсчитываются | «В девять утра — одна строка: выручка, чеки, средний чек и сравнение с прошлым четвергом.» |
| 30–40 с | «Сделать сегодня»: 3 карточки появляются по очереди, нажимается «Утвердить» | «Система сама находит, что важно сегодня: шесть удалений у одного официанта, провал после обеда, плохой отзыв. Решаете вы — одной кнопкой.» |
| 40–50 с | Таблица официантов, подсвечивается лучший; меню: «звёзды», «поднять цену», «убрать» | «Видно, кто продаёт лучше, и сколько принесёт, если все будут допродавать так же. Какие блюда кормят ресторан, а какие только занимают место в меню.» |
| 50–58 с | Фудкост по неделям растёт, всплывает «говядина +12%»; счётчик потерь 186 тыс. | «Фудкост растёт — вы узнаете почему, не через месяц, а через неделю.» |
| 58–68 с | Цепочка «реклама → переписки → брони → гости», цифра «×11» | «Реклама — не в лайках, а в гостях: сколько стоит бронь и сколько принёс каждый вложенный тенге.» |
| 68–78 с | Портрет клиента: сегменты «бизнес-ланч», «семейный ужин», «компании», «доставка» с долями выручки | «Вы видите своих гостей: кто приходит на обед, кто на семейный ужин, кто заказывает доставку — и на кого направить рекламу.» |
| 78–85 с | Instagram: подписчики и охват растут, рейтинг 2ГИС 4,4 → 4,6 | «Instagram и отзывы растут вместе с выручкой.» |
| 85–92 с | Шесть ИИ-сотрудников (иконки) и график выручки вверх; логотип REVION, контакты | «REVION — цифровой офис вашего ресторана. Цифры — каждое утро, решения — за вами.» |

Для ролика нужен ещё один демо-экран — «Портрет клиента» (сегменты гостей); остальные экраны уже есть в 3 слайдах «REVION · ресторан».
