# План офиса

Офис работает на продажи квартир в ЖК: сотрудники закрывают всю воронку
«реклама → Instagram → WhatsApp → сделка». Решения ниже приняты вместе
с владельцем 30.09.2026.

## Исходные условия

| | |
|---|---|
| Тариф | Claude Max 5x |
| Где работает | Компьютер владельца, Windows. Работает, пока он включён |
| Управление | Экран офиса в браузере и Telegram-бот |
| Руководитель | Составляет план → владелец подтверждает → раздаёт |
| Общение сотрудников | Только через руководителя |
| Язык | Русский |
| Для кого | Только для себя, не на продажу |
| Внешние действия | Публикации, сообщения людям, траты кредитов — только после «да» владельца |

## Сотрудники

| Сотрудник | Что делает | Доступ | Этап |
|---|---|---|---|
| Руководитель | Раскладывает поручение на шаги, после «да» раздаёт | Без инструментов, только план | 1 |
| SMM | Посты, сторис, контент-план, УТП, готовые картинки в стиле Altyn Qala | База знаний, присланные материалы | 1 |
| Монтажёр | Reels «Ход строительства» из видео владельца | Видео, ffmpeg | 2 |
| Маркетолог-аналитик | Реклама Meta и статистика Instagram, проверка УТП | Только чтение | 3 |
| Аналитик продаж | Шахматка, форма «Итог диалога», топ вопросов и возражений | Только чтение | 3 |

Главные связки:
- аналитик продаж видит, что не продаётся, — SMM продвигает именно это;
- аналитик собирает частые вопросы и возражения — SMM делает УТП и контент
  под них, маркетолог проверяет варианты УТП рекламой;
- тот же список вопросов превращается в готовые ответы для менеджера Асель.

## Как устроено

```
Владелец ──(экран офиса / Telegram)──▶ Руководитель: план
                                          │ владелец жмёт «Утвердить»
                                          ▼
                                   Очередь задач
                                          │ диспетчер, максимум 2 одновременно
                                          ▼
                      Сотрудник = один запуск claude -p в папке задачи
                                          │ поток событий
                                          ▼
                     Экран офиса и Telegram: кто чем занят, результат
```

- **Простой ничего не стоит.** Сотрудник запускается под задачу и выключается.
- **Облегчённый запуск:** своя короткая инструкция, только нужные инструменты,
  `--restricted`, без MCP, потолок ходов и бюджета.
- **Папка задачи:** `work/<задача>/`. Внутри копия базы знаний `_база`,
  присланные файлы `_материалы`, результаты коллег `_от_коллег`. Сотрудник
  видит только эту папку — оригиналы тронуть не может.
- **Общение через файлы.** Если шаг зависит от другого, результат первого
  кладётся во второй как `_от_коллег`. Руководитель ничего не пересказывает.
- **Счётчик лимита** — из события `rate_limit_event`, которое присылает сам
  Claude.
- **Ключ API не используется.** Офис убирает `ANTHROPIC_API_KEY` из окружения
  сотрудников, чтобы работа шла по подписке, а не по счёту.

## Этапы

| Этап | Что появляется | Что получает владелец |
|---|---|---|
| **1** | Диспетчер, руководитель, SMM, пиксельный экран, Telegram-бот, база знаний | Поручения с телефона и компьютера, видно, кто чем занят, посты по фактам ЖК |
| 2 | Монтажёр, Google Диск для видео, недельный ритм, шаблоны картинок | Reels «Ход строительства — 2 очередь» из трёх видео, план постов по понедельникам |
| 3 | Instagram и реклама Meta, шахматка через Google Таблицу, форма «Итог диалога» | Отчёты по воронке, голос клиента, УТП |

## Подключения

| Что | Как | Цена | Риск блокировки |
|---|---|---|---|
| Telegram-бот | Официальный Bot API, long polling — сервер не нужен | 0 | Нет |
| Видео | Google Диск для компьютера | 0, до 15 ГБ | Нет |
| Instagram | Официальный API, бизнес-аккаунт | 0 | Нет |
| Реклама Meta | Marketing API, только чтение | 0 | Нет |
| Шахматка | Портал → Google Таблица | 0 | Нет |
| WhatsApp | Форма «Итог диалога», экспорт чатов, быстрые ответы | 0 | Нет |
| Картинки-макеты | HTML-шаблоны в стиле Altyn Qala → PNG через Chrome на компьютере (готово 01.10.2026) | 0 | Нет |
| Генерация фото | Higgsfield | Кредиты | Нет |
| Монтаж | ffmpeg | 0 | Нет |

## Монтаж — задание от владельца

- Длина 15 секунд, вертикальное видео.
- Три обрезанных фрагмента из трёх видео.
- Текст: «Ход строительства», под ним «2 очередь».
- Логотип строительной компании.
- Музыку владелец ставит сам при публикации — трендовые звуки Instagram.

## Правила, которые не нарушаем

1. Факты о ЖК — только из базы знаний. Недостоверная реклама недвижимости
   запрещена и подводит покупателя.
2. Квартиры и ЖК — только на настоящих фото. Генерация — для фонов и атмосферы.
3. Ничего наружу без «да» владельца: публикации, сообщения, траты кредитов.
4. WhatsApp — только официальными способами.
5. Персональные данные клиентов вырезаются до того, как текст попадёт в Claude.
