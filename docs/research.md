# Исследование: виртуальный офис агентов

30 сентября 2026. Пять направлений, у каждого независимая проверка ключевых
утверждений. Здесь выводы, на которых стоит решение. Числа и правила Anthropic
меняются — даты проверки указаны.

---

## Главный вывод

Сам офис токенов не тратит. Пиксельная картинка рисуется из журналов работы
Claude Code. Токены тратят только реальная работа сотрудников и решения
руководителя. Поэтому дешёвый офис — это тонкая оболочка над встроенными
возможностями Claude Code, а не тяжёлый фреймворк.

## Что уже есть готового

| Проект | Что умеет | Чего нет |
|---|---|---|
| [Pixel Agents](https://github.com/pixel-agents-hq/pixel-agents) — MIT, ~9,5 тыс. звёзд | Пиксельный офис, персонажи печатают и читают вместе с агентом | Только наблюдает: ни задач, ни руководителя |
| [Agent Campus](https://github.com/mateovalle/agent-campus) — MIT, v0.2 | Офис, чат с агентом, списки задач, ассистент-руководитель | Ранняя версия, нет переписки агентов, нет русского и Telegram |
| [Gander](https://github.com/weellio/gander) — MIT | Клик по агенту, очередь, Telegram | Нет руководителя, заточен под программирование |
| [Claw-Empire](https://github.com/GreenSheep01201/claw-empire) | «Компания» с CEO и отделами | Прожорливый, заброшен с марта, запускает агентов **без проверок разрешений** |
| [AI Town](https://github.com/a16z-infra/ai-town) | Пиксельный город с ИИ-жителями | Социальная симуляция, постоянно тратит токены, к работе отношения не имеет |

Проверено в коде: Pixel Agents не использует ни одной языковой модели, его хук
ничего не добавляет в контекст Claude. Claude Office Visualizer по умолчанию
делает по 3 запроса к Haiku на каждый ход ради сводок — это расход,
которого у нас не будет.

## Что умеет сам Claude Code

| Возможность | Состояние | Для нас |
|---|---|---|
| Запуск `claude -p` с потоком событий | Стабильно | Основа: сотрудник работает только под задачу |
| `--tools`, `--restricted`, `--strict-mcp-config`, `--system-prompt` | Проверено 30.09 | Сотрудник видит только свою папку, лишнего нет |
| `--json-schema` | Проверено 30.09 | Руководитель отдаёт план строго по схеме |
| `--max-turns`, `--max-budget-usd` | Проверено 30.09 | Потолок на каждую задачу |
| Событие `rate_limit_event` в потоке | Проверено 30.09 | Точный счётчик лимита на экране офиса |
| Фоновые сессии, `claude agents --json` | Предпросмотр | Не нужны для первого этапа |
| Переписка между сессиями | С v2.1.224 | Не нужна: сотрудники общаются через руководителя |
| Agent Teams | Экспериментально | Не берём: ~7× токенов, нельзя запускать из `-p` |

## Замер: облегчённый запуск

Реальные запуски 30.09.2026:

| Запуск | Входящих токенов | Условная цена |
|---|---|---|
| Пустой ответ, облегчённый режим | 913 | $0,001 |
| План руководителя со схемой | 1 754 | $0,005 |
| Сотрудник читает файл и пишет пост | несколько тысяч | $0,02 |
| Для сравнения: обычный старт Claude Code | 20 000–60 000 | — |

Облегчённый режим: своя короткая инструкция вместо стандартной, только нужные
инструменты, без MCP и чужих настроек.

## Где сгорают токены

| Пожиратель | Масштаб |
|---|---|
| Agent Teams | ~7× против обычной сессии |
| Стандартные настройки: Opus и 20–60 тыс. токенов служебного текста на старте | Облегчённый режим дешевле в 5–12 раз |
| Переписка агентов между собой | Каждое сообщение — полный ход получателя |
| Руководитель, который пересказывает работу сотрудников | Платите дважды |
| «Дежурство» с периодическими проверками | До сотен долларов в месяц впустую |

## Подписка и цены

- Работа через `claude -p` и Agent SDK списывается из лимитов подписки Pro/Max.
  Отдельный кредит для SDK, объявленный на 15 июня 2026, приостановлен
  ([поддержка Anthropic](https://support.claude.com/en/articles/15036540-use-the-claude-agent-sdk-with-your-claude-plan)).
- Параллельные агенты тратят общий лимит пропорционально.
- Цены API за миллион токенов: Haiku 4.5 — $1/$5, Sonnet 5.5 — $2/$10,
  Opus 5.5 — $4/$20.
- Anthropic не публикует размеры 5-часового и недельного лимита в токенах.
  Реальную долю меряем по счётчику.

## Качество: какую модель кому

Тест 30.09: Haiku в посте по одной строке фактов выдумал «центр Астаны» и
перепутал «2 очередь» с «вторым кварталом». Вывод: тексты для клиентов пишет
Sonnet со строгим правилом «факты только из базы». Haiku — только для
механической разметки.

## Инструменты и роли

- **Картинки** — Higgsfield, уже подключён. Картинка 0,25–1,5 кредита,
  видео 5 секунд — 8,75–35 кредитов. Кредит ≈ $0,033–0,052.
- **Instagram API** — нужен бизнес-аккаунт, публикация своих постов без
  проверки приложения. Картинки только JPEG по публичной ссылке, Higgsfield
  отдаёт PNG — нужна конвертация.
- **WhatsApp** — неофициальные подключения через WhatsApp Web нарушают правила
  и грозят блокировкой номера
  ([WhatsApp FAQ](https://faq.whatsapp.com/1217634902127718)). Используем форму
  «Итог диалога», официальный экспорт чатов и быстрые ответы.
- **Маркетинговые сообщения в Казахстане** требуют предварительного согласия
  получателя (закон № 94-V). Сотрудники людям не пишут.
